## Tour Booking Website ##

A full-stack tour booking website that allows tourists to search destinations, view tour packages, check availability and make bookings online.

## Features ##

- Search for tourist destinations
- View detailed tour packages
- Check availability of packages
- Book tours online
- Responsive design for desktop and mobile

## Technologies Used ##

- Frontend: HTML5, CSS3, JavaScript
- Backend: PHP
- Tools: Visual Studio Code
